# 老周的台架

浏览器里的单缸四冲程发动机试验台和直线赛道，外加一串修理铺工单和一间自己的车库。气缸压力、进排气管里的气柱、排气声都由同一个按曲轴转角求解的物理内核算出来：改缸径、凸轮、排气管长度或点火角，扭矩曲线和声音一起变；改过头，连杆会断，气门会撞活塞，活塞顶会被爆震打穿。

## 怎么玩

### 工单

15 张客户工单，从“等红灯就熄火的 250”到“单缸之王”，后四张在赛道上验收（零百、爬坡、极速、涡轮 250 跑四百米）。每单从客户的发动机开始，左边写着要求：

- **★** 满足全部要求（例如最大功率 ≥ 18 hp、消音器必须原厂、只加 92 号油）
- **★★** 再冲到加分线
- **★★★** 并且零件花费不超过预算

改装单按零件列出，每个零件有价格：动了它的任何参数就等于买了它，改回原值不收钱。ECU 随便调，不花钱。改好了点 **提交验收**：后台 Worker 里会用一台一模一样的发动机按固定流程跑一遍（起动、怠速、全油门扫转速，有的单还有空轰、红线耐久、收油放炮），保护关闭——扛不住就会坏。拿到一颗星解锁下一单；卡住了点 **问老周** 看门道。

每一单都有一个参考解能拿三星（`src/game/solutions.ts`，`npm run jobs` 会验证），而且大多数单子三星需要在预算里做取舍。

### 自己的车库

自己的车：台架上随便改、随便炸；新零件先装上试，满意了再「结账」，买过的零件以后怎么调都不再收钱。接工单每颗星 ¥600、声望 10；在赛道上用付清的车跑出铜、银、金牌也发奖金和声望。声望解锁缸头、可变气门正时、涡轮和中冷、齿比组、快排等高级零件，钱可以买 650 大单缸、450 赛机、卡丁车和赛道车（「车库」面板，`G`）。

想完整重来：开始页底部「清空进度，重新开始」（会二次确认），工单、钱、零件、奖牌、纪录和自己的车全部回到第一天。

### 赛道

按 `T` 把台架换成赛道：发动机还是那台发动机（声音、爆震、增压全是实时算的），通过离合器、变速箱、链条和后轮推着车走，后轮有滑移曲线，加速时重心后移，前轮可能抬起来，抬过头会翻。五个项目：零百加速、四百米、1 公里 12% 爬坡、极速、最高挡 50→100 超车。可以让车手骑，也可以自己拧油门、按 `↑` `↓` 换挡；最好成绩会作为影子陪跑，跑完给出 60 英尺、100 米、0–100 分段、过线速度、打滑和抬头时间、换挡掉速和车速曲线。「整车」面板（`A`）：车型（街车、赛道车、卡丁车）、主减速比、每个挡的齿比、轮胎、减重、底盘几何、整流罩、离合器、快排、放离合快慢，以及 ECU 里的弹射起步、每挡换挡转速、快排断火时间、牵引力控制、防抬头。

### ECU

除了总点火修正、空燃比、断火和怠速，还有：

- **点火表、空燃比表、进气凸轮表**：转速 × 负荷（进气压力 / 大气压，0.2–2.0）的二维表，点选或拖出一片格子加减、设值、抹平；橙色圆点是发动机此刻在表上的位置。
- **增压目标**：按转速的增压曲线（需要涡轮），防迟滞。
- **怠速与断油**：怠速控制力度、怠速点火储备、节气门缓冲开度和时间、松油门断油的进入 / 恢复转速和延时、起动空燃比、加速加浓（进气道油膜模型：补不够，猛开油门会瞬间变稀发闷）。

新硬件：涡轮（尺寸决定迟滞和高转憋气）、中冷、喷油嘴（占空比到 90% 就喷不出更多）、可变气门正时相位器、稳压腔容积。

### 发动机画面

剖面图回放的是上一个完整循环：火焰从火花塞往外烧，烧过的气体按温度变色，爆震时末端混合气会闪。进排气道的颜色跟着气门口压力走（蓝 = 真空，橙 = 正压），能看到调音管里的压力波；气流点会跟着实际流量走，倒流时往回跑。连杆受压发橙、受拉发蓝，接近拉断时变粉。右边的表盘把 720° 画成一圈，标出四个冲程、进排气门开闭、重叠角、点火和燃烧区间；下面是这一刻的缸压、缸内气体、气门流量、气门口压力、连杆受力和活塞速度。可以切到超慢或暂停，拖动画面逐度看。

### 老周

左栏（工单卡下面）是台架老师傅老周：

- **带我入门**：七步，从起动到用测功机对比两条曲线，每步都能让他代劳。
- **盯着你**：你碰哪个参数，他讲它管什么、该看哪里；改完会用和内核同一套公式检查气门飘浮、连杆疲劳、爆震、混合比，扭矩掉了会给你撤销按钮。
- **保护模式**：开着时内核会把实际断火压在零件安全线上，连杆和气门到极限会直接切断而不是炸。关掉它才能真的炸。
- **给老周定目标**：列几个指标（最大功率、最大扭矩、某转速的扭矩或功率、断火转速、怠速、轰油回怠速、空轰时间、放炮响数、零百 / 四百米 / 爬坡 / 超车用时、极速、预算、排量、油号、活塞损伤、连杆疲劳……），每个标成「必须」或「最好」，再勾上允许他动的发动机和车上零件。他像工程师一样干活，后台 Worker 里同时开几台私有发动机：
  1. **体检**：按验收流程跑一遍，读每个转速点的充气效率、爆震退角、喷油嘴占空比、增压、实际空燃比，以及赛道上的打滑、抬头和换挡掉速，说出是什么在卡着（爆震、高转喘不上气、功率到断火还在涨、喷油嘴到头、涡轮迟滞或憋气、断油恢复太晚熄火、末挡太短……）。
  2. **标定**：像在测功机上那样逐个转速点找点火（到扭矩不涨或爆震线前 1.5°）、空燃比（出力最好里最浓的）、凸轮相位和增压上限，写进 ECU 表。
  3. **对症**：每条诊断对应的办法同时试，几个都有用就合在一起；动了爆震线的零件装上后重新标点火；预算内的办法优先。
  4. **整车**：按扭矩曲线算每个挡的最快换挡点（下一挡轮上推力超过这一挡的地方），网格试弹射转速、放离合快慢和牵引力控制。
  5. **细调**：在所有相关旋钮（含转速、怠速、断油、齿比、车重……）上做模式搜索，退掉没必要的零件。
  6. **复核**：按正式流程再跑，换个日子（另一组随机扰动）再跑一遍，不稳就退点火、降增压留余量；结果不如原样就原样还你。

  “轰油门松开不熄火”是他自己守的底线。找到的方案直接装上，测功面板留下前后两条曲线，一键可换回。工单里会按这单的要求自动填好目标；赛道上跑完一趟，他会说哪里慢、给出对应按钮，也能一键让他把这项调快。
- **熄火托管**：自己的车开着「保护」时熄火，老周会在后台把恢复供油、点火储备、节气门缓冲、怠速控制等几种改法同时试一遍，装上最小的那个能稳住的改法并重新打着；工单里只提议，不替你动手。
- **现场调 ECU**（只在自由试验台）：在测功机上真实地扫点火角（找扭矩最大且不爆震的点）和全油门 λ，前后各拉一条曲线对比。
- **换新活塞连杆**（读数栏）：把台架上磨出来的活塞损伤和连杆疲劳清零，不改规格、不花钱。
- **拆机报告**：坏了以后告诉你为什么，并能一键按他的建议改好再换零件。

## 开发

```bash
npm install
npm run dev        # http://localhost:3000
npm run check      # 类型检查 + lint + 测试
npm run build
npm run bench      # 无界面跑各预设：起动、怠速、空轰、全油门扭矩表、点火角扫描
npm run jobs       # 每张工单：原样必须不及格，参考解必须拿到星（可加工单 id 过滤）
npm run goals      # 把每张工单交给老周（体检、标定、对症、整车、细调、复核），从客户原车开始，看他能拿几颗星
npm run render     # 把一段起动到收油的过程渲染成 out/*.wav，并打印各段电平
```

## 架构

```
src/
  sim/      物理内核（纯 TS）：config 参数、ECU 表与派生量，core 曲轴转角求解器（含涡轮、相位器、喷油嘴、油膜），
            vehicle 离合器、变速箱、轮胎滑移、重心转移和抬头，race 计时项目与车手，snapshot 给界面的快照
  audio/    synth 声音合成，dsp 基础滤波器，runner 内核+合成器+消息协议，
            engine.worklet 在音频线程里按采样率运行，host 主线程宿主（无音频时退回主线程静音运行）
  state/    zustand：benchStore（持久化的发动机/ECU/台架/测功曲线），liveStore（快照、平滑读数、示功图、事件），
            controlStore（操作输入），uiStore（抽屉、正在调的参数和改动前基线），engineLink（连接宿主、测功记录、自动扫转速）
  game/     工单：acceptance 验收流程（纯函数，跑在 Worker 里），jobs 工单与判星，parts 零件价目，career 车库的钱、声望、解锁和奖牌，
            session 工单/自由台架切换与验收调度，store 进度与草稿持久化，solutions 参考解
  mentor/   老周：advice 装配体检和拆机复盘，tuner 自动标定（只依赖台架接口，可无界面测试），
            goals 目标与打分，engineer/ 工程师流程（诊断、逐点标定任务、对症、整车、复核），search 细调用的模式搜索，
            pool Worker 池（验收、计时项目、标定任务），quest 目标任务的调度，autopilot 熄火托管，raceCoach 赛道点评，
            brain 盯盘、救场、课程和实机调校，voice 台词，params 参数讲解，lessons 入门课程
  ui/       剖面图、赛道、转速表、读数、示波器、ECU 表格编辑器、抽屉面板、车库、失效报告；ui/job 工单卡、工单列表、验收对话框
scripts/    bench、jobs、goals、render
```

内核以单区缸内模型为核心：质量和能量守恒、可压缩孔口流动的气门和节气门、带惯性的进气道和排气头段气柱、Wiebe 燃烧、Livengood-Wu 爆震积分、Woschni 传热、Chen-Flynn 摩擦、飞轮动力学。它在 AudioWorklet 里每个音频采样推进一次（必要时细分到每步不超过 0.6° 曲轴转角）。排气门的瞬时质量流量驱动排气管波导，最后得到你听到的声音。
